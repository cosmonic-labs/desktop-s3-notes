Notes in an S3 bucket

A WebAssembly component on Cosmonic Desktop. It imports wasmcloud:blobstore as (implements assets); the host routes that to the S3 binding named assets. Each note is one object in the bucket cosmonic-notes. The component never sees the endpoint or the keys.
